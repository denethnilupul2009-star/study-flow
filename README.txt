StudyFlow Study Kit — Brave Browser Edition
===========================================

This is a single-file study planner designed to run in Brave or another modern browser.

HOW TO OPEN
1. Extract this ZIP.
2. Open the StudyFlow_StudyKit folder.
3. Double-click index.html, or right-click it and choose Open with > Brave.
4. Keep using that same browser profile for saved data.

FEATURES
- Pomodoro timer: adjustable focus and break durations
- Daily task checklist with subject tags
- Autosaved study notes per day
- Subject focus selector
- Flashcards with reveal-answer controls
- Exam countdown
- Study minutes, completed tasks, focus sessions, weekly chart
- Export / import JSON backup

DATA PERSISTENCE
- Tasks, notes, flashcards, exam date, and progress save automatically in localStorage.
- Closing the tab or Brave normally does not delete saved data.
- Do not use Private/Incognito windows for persistent storage.
- Clearing Brave's site data/browser data, using a different browser profile, or moving to another PC may remove or hide the saved data.
- Use Backup & restore > Export backup regularly. Save the JSON file somewhere safe.
- Data stays locally in the browser; this app does not upload it to a server.

If your browser is configured to clear site data on exit, disable that option for your normal Brave profile to keep your progress.
